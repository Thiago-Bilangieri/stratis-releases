# Stratis

Instalador e atualizações do Stratis (só binários; o código-fonte é privado).

**Instalar:** abra a [última release](https://github.com/Thiago-Bilangieri/stratis-releases/releases/latest) e descarregue `StratisApp-win-Setup.exe`.

O Windows SmartScreen pode avisar no primeiro arranque porque o instalador não está assinado: "Mais informações" → "Executar assim mesmo". O Stratis atualiza-se sozinho antes de abrir.
